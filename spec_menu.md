# Техническое задание: Верхняя навигационная панель (Setup Wizard Header)

## 1. Общие требования и верстка
- Компонент представляет собой закрепленную верхнюю панель, которая всегда остается видимой при прокрутке страницы (`sticky top-0`, `z-50`).
- Внешний контейнер имеет белый фон для светлой темы и соответствующий цвет фона для темной темы (`bg-white dark:bg-bg-primary`).
- Панель отделена от основного контента нижней рамкой (`border-b border-slate-200 dark:border-border-primary`).
- Имеет внутренние отступы (padding) по горизонтали и вертикали (`px-6 py-4`).
- Внутренний контент ограничен по максимальной ширине и отцентрирован (`max-w-7xl mx-auto`).
- Внутренний контейнер использует Flexbox для распределения элементов по краям (`flex items-center justify-between`).

## 2. Элементы левой части панели
- Общий Flexbox контейнер с отступами между элементами (`gap-4`).
- **Логотип компании (USClosersLogo)**:
  - Выступает в роли интерактивной кнопки.
  - Содержит обработчик события клика (`onClick`), который возвращает пользователя на главную страницу с сохранением текущего языка (`/{lang}`).
  - Имеет анимацию плавного изменения прозрачности при наведении курсора (`hover:opacity-80 transition-opacity`).
  - Высота иконки логотипа зафиксирована (`h-8`).

## 3. Элементы правой части панели
- Общий Flexbox контейнер с отступами между элементами (`gap-4`).
- **Переключатель языков (LanguageSwitcher)**:
  - Стандартный компонент смены локализации интерфейса.

*Примечание: Согласно требованиям, индикатор шагов и прогресс-бар настройки исключены из данного описания.*
