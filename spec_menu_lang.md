# Техническое задание: Компоненты смены языка и темы

## 1. Переключатель языков (LanguageSwitcher)

### Внешний вид и структура
- **Контейнер**: `relative inline-block text-left`. Меню открывается при наведении курсора (`onMouseEnter`, `onMouseLeave`).
- **Кнопка вызова (Trigger)**:
  - Верстка: Flexbox-контейнер (`flex items-center gap-2`), внутренние отступы `px-3 py-2`, скругление углов `rounded-xl`.
  - Типографика: жирный шрифт `font-bold`, размер `text-sm`, цвет текста `text-text-secondary`.
  - Эффекты при наведении: изменение цвета текста на `text-text-primary`, фона на `bg-bg-surface`, и появление рамки `border-border-primary` (по умолчанию рамка прозрачная `border-transparent`).
  - Содержимое:
    - Иконка флага страны в виде круга (`w-4 h-4 rounded-full opacity-90 shadow-sm`).
    - Буквенный код языка (например, "EN"). Текст скрыт на мобильных устройствах и отображается только начиная с брейкпоинта `sm` (`hidden sm:inline`). Стили текста: `tracking-wider text-[11px]`.
- **Выпадающее меню (Dropdown)**:
  - Анимация: Плавное появление (изменение прозрачности от 0 к 1) и смещение по оси Y (выезжает сверху вниз для хедера). Используется библиотека `motion/react` (`AnimatePresence`).
  - Позиционирование: Абсолютное (`absolute z-50 right-0`). В хедере открывается вниз (`top-full`).
  - Оформление контейнера: Ширина `w-28`, сильное скругление углов `rounded-xl`, выраженная тень `shadow-[0_10px_40px_rgba(0,0,0,0.12)]`, рамка `border border-border-primary`.
  - Фон меню: Полупрозрачный цвет фона с эффектом размытия (`bg-bg-primary/95 backdrop-blur-md`), внутренние отступы `p-1.5`.
- **Элементы меню (Кнопки языков)**:
  - Расположены в столбец с отступом между собой (`flex flex-col gap-1`).
  - Верстка элемента: Flexbox (`flex items-center gap-3 w-full text-left`), отступы `px-3 py-2.5`, скругление `rounded-lg`, размер текста `text-sm`.
  - **Активное состояние** (выбранный язык): Цвет фона `bg-accent-primary`, белый цвет текста `text-white`, жирный шрифт `font-bold`, небольшая тень `shadow-sm`.
  - **Неактивное состояние**: Цвет текста `text-text-secondary`, при наведении фон `hover:bg-bg-surface` и цвет текста `hover:text-text-primary`, начертание `font-medium`.
  - Содержимое элемента: Флаг-кружок (`w-4 h-4 shrink-0`) и код языка (`flex-1 font-bold tracking-wider`).

### Логика работы
- При клике на другой язык, компонент заменяет языковой префикс в текущем URL-пути (например, `/en/setup` на `/es/setup`) и выполняет переход с параметром `replace: true` (чтобы не засорять историю браузера).
- Выпадающее меню скрывается после выбора языка.

## 2. Переключатель темы (ThemeToggle)

### Внешний вид и структура
- **Кнопка**:
  - Верстка: `relative p-2.5 rounded-xl flex items-center justify-center overflow-hidden`.
  - Цвета: текст `text-text-secondary`, при наведении `hover:text-text-primary` и фон `hover:bg-bg-surface`.
  - Рамка: прозрачная по умолчанию, при наведении появляется `hover:border-border-primary`.
  - Анимация: `transition-all`.
- **Иконки (Солнце и Луна)**:
  - Используются иконки из `lucide-react`. Размер иконок `w-4 h-4`.
  - Иконка Солнца спозиционирована абсолютно, иконка Луны - относительно.
  - **Анимация переключения** (`transition-all duration-500`):
    - В **Светлой теме**: Солнце имеет `opacity-100 rotate-0 scale-100`, Луна спрятана (`opacity-0 -rotate-90 scale-50`).
    - В **Темной теме**: Солнце спрятано (`opacity-0 rotate-90 scale-50`), Луна имеет `opacity-100 rotate-0 scale-100`.

### Логика работы
- Компонент отслеживает наличие класса `dark` на теге `<html>` (используя `MutationObserver` для синхронизации, если тема переключается в другой вкладке или другим скриптом).
- При нажатии:
  - Переключает класс `dark` на `document.documentElement`.
  - Записывает выбранную тему в `localStorage` (ключ `theme`, значения `dark` или `light`).
  - Обновляет локальное React-состояние для запуска анимации иконок.
